# ほしくずの勇者

ブラウザで遊べる、オリジナルのレトロ風コマンドRPGです。
夜の塔にすむ竜ノクスウィルムを倒して、空の星を取り戻しましょう。

HTMLファイル1つで動きます。インストールやビルドは要りません。

## 遊び方

- `index.html` をブラウザで開くだけで遊べます。
- GitHub Pages で公開すれば、スマホからURLで遊べます（下の手順を参照）。

### 操作

| | PC | スマホ |
|---|---|---|
| 移動 | 矢印キー / WASD | 十字キー |
| 決定 | Z / Enter / Space | Aボタン |
| もどる・メニュー | X / Esc | Bボタン |

メニューやメッセージはタップ・クリックでも進めます。

## 特徴

- **4人パーティー**：ゆうしゃ・せんし・まほうつかい・そうりょ
- **ジョブチェンジ**：お城で仲間の職業をいつでも変更（ゆうしゃ / せんし / まほうつかい / そうりょ / とうぞく）
- **コマンドバトル**：最大3匹の敵グループ、全体攻撃、回復、蘇生、特技
- **装備5枠**：ぶき・よろい・たて・かぶと・そうしょく
- **隠し装備**：マップのどこかに5つ。町の人の話がヒント
- **セーブ**：宿屋に泊まるか王様に話すと、ブラウザ（localStorage）に記録
- **ふしぎな星**：メニューから選ぶと、全員Lv30＋隠し装備フル装備になるお楽しみ機能

## GitHub Pages で公開する手順

1. GitHub で新しいリポジトリを作る（例：`hoshikuzu-yusha`）
2. このフォルダの `index.html` と `README.md` をアップロード
   （リポジトリ画面の **Add file → Upload files** にドラッグ＆ドロップ → **Commit changes**）
3. リポジトリの **Settings → Pages** を開く
4. **Source** を `Deploy from a branch`、**Branch** を `main` / `/(root)` にして **Save**
5. 1〜2分待つと `https://<ユーザー名>.github.io/hoshikuzu-yusha/` で遊べます

## 技術メモ

- 素の HTML / CSS / JavaScript（ライブラリなし）
- グラフィックは Canvas にドット絵をコードで描画、効果音は Web Audio API で生成
- フォントは Google Fonts の DotGothic16
- セーブデータはブラウザごと・端末ごとに保存されます
